# Rao's Mobiles Website

Enterprise-grade e-commerce & mobile repair service web application for **Rao's Mobiles** (Narasaraopet).

## Features
- **Shop Catalog**: Browse genuine smartphones, original display combos, mobile cases, tempered glasses, and chargers.
- **Repair Services**: Book instant screen replacements, battery services, and certified chip-level mobile repairs.
- **Unified Glass Navbar**: Clean, translucent floating capsule header navigation bar with integrated search and auth buttons.
- **Responsive Layout**: Full 100vh hero section with crisp background video and floating circular WhatsApp CTA widget.

## Deployment on Render
1. Push to GitHub repo `https://github.com/bathikadileep/rao-website.git`.
2. Connect repository to Render as a Web Service.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
